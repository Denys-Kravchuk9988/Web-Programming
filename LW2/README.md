# NestJS Project

Це серверна частина проєкту, розроблена з використанням [NestJS](https://nestjs.com/) — прогресивного Node.js фреймворку для створення ефективних і масштабованих серверних додатків.

## Встановлення

Якщо встановлений Node.js тоді можна виконати наступні команди:

```bash
npm install
```

## Локальний запуск

```bash
npm run start
```

## Запуск через Docker

```bash
docker-compose up --build
```

Наступні запуски:

```bash
docker-compose up
```

Зупинка контейнерів:

```bash
docker-compose down
```

## Структура проєкту

- `src/` – основний код NestJS (модулі, контролери, сервіси)
- `Dockerfile` – інструкції для створення Docker-образу
- `docker-compose.yml` – конфігурація для запуску кількох сервісів
