# Лабораторна робота №1

## Структура проєкту

```
🔍 ЛР1/
├── Dockerfile
├── docker-compose.yaml
├── lab_1.sh
├── results/
└── Звіт до 1 ЛР.docx/pdf
```

---

## Як запустити

### 1. Встановлення

- Потрібно встановити [Docker Desktop](https://www.docker.com/products/docker-desktop) (обов’язково з підтримкою **WSL2** для Windows).
- Перевірте будь ласка, що файл `lab_1.sh` має кінець рядків у форматі `LF`, а не `CRLF` (щоб уникнути помилок в Unix-середовищі).

### 2. Запуск

У терміналі, перебуваючи в кореневій директорії проєкту, виконайте наступну команду:

```bash
docker-compose up --build
```

---

## Результати

Результати DNS-запитів будуть автоматично збережені у папці `./results/` після запуску контейнера.

---

Щоб зупинити контейнер, потрібно ввести:

```bash
docker-compose down
```

Результати залишаться у папці `results/`.
